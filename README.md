# STEP Java Programming Repository

This repository contains solutions and problem sets organized week by week.

## Structure
- **`week1/`**: 
  - `problems/`: Day 1 Live-Coding Session problems (Rock-Paper-Scissors, Palindrome Checker, BMI Calculator, First Non-Repeating Character, Reverse Customer Name)
  - `assignment/`: Homework assignments (Exam Hall Duplicate Checker, Movie Review Profiler, Traffic Signal Streak, Typing Speed Accuracy, Warehouse Balancer)
- **`week2/`**:
  - `live/`: Live class exercises
  - `assignment/`: Weekly assignments
- **`week3/`**:
  - `practice/`: OOP practice & capstone
  - `homework/`: OOP homework assignments & capstone
